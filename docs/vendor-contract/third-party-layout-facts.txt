Facts about the physical XER layout, read 2026-11-06 from pages and source files I loaded. NONE of these is Oracle's. They are what two open-source readers and a national
archive registry say. Short quotations only, as evidence; no third-party code is copied into xerlane (xer-reader is GPL-3.0, MPXJ is LGPL-2.1, xerlane is MIT).

== A. PRONOM, UK National Archives, format fmt/1455 "Primavera P6 Project Management XER File"
URL: https://pronom.nationalarchives.gov.uk/fmt/1455
  Description: "An ASCII based file used to store project information with accompanying tables and fields."
  Developed by: Oracle
  Internal signature: "BOF: 'ERMHDR' EOF:0D0A"   (byte sequence 45524D484452 at offset 0; byte sequence 0D0A at the end of the file)

  reader.py:  CODEC = "cp1252"
  reader.py:  if not file_contents.startswith("ERMHDR"): raise ValueError(... is invalid XER file)
  reader.py:  ermhdr = re.search(r"(?<=ERMHDR\t).+", data); return ermhdr.group().split("\t")      (the header line is tab separated)
  reader.py:  _file_info[0] = export_version, [1] = export date parsed with "%Y-%m-%d", [4] = export_user, [7] = currency
  reader.py:  data.split("%T\t")   (a table starts with a line "%T<TAB><table name>")
  table.py:   _lines = re.split(r"\r?\n", data); the first line is the table name; the second line holds the column labels: _lines.pop(0).strip().split("\t")[1:]   (a "%F<TAB>..." line)
  table.py:   row.split("\t")[1:] for row in _lines if row.startswith("%R")   (a row is a "%R<TAB>..." line)
  reader.py:  re.compile(rf"%T\t{name}\r?\n(.|\s)*?(?=%T|%E)")   (the file ends with a "%E" line)
  table.py:   DATE_HR_FORMAT = "%Y-%m-%d %H:%M"; an empty string value is None
  table.py:   a type is chosen by the column NAME suffix: *_date and *_date2 are dates; *_cost, *_hr, *_pct, *_qty, *_rate are floats; *_id, *_cnt, *_num are integers; *_flag is Y or N
  table_data.py: key columns: CALENDAR clndr_id, PROJECT proj_id, PROJWBS wbs_id, RSRC rsrc_id, TASK task_id, TASKPRED task_pred_id, TASKRSRC taskrsrc_id
